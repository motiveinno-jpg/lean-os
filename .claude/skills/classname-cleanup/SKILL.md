# 클래스 네이밍 일괄 정리 프로젝트

규칙 본문(마커만 남기고 스타일은 globals.css `@apply` 로)은 루트 `CLAUDE.md` 의
"🏷️ 클래스 네이밍" 섹션에 있다. 여기에는 **일괄 정리 프로젝트의 배경과 이력**만 둔다.

## 배경·승인 이력

- **2026-07-08**: 규칙 도입. 앞으로 작성하는 코드에 적용.
- **2026-07-15**: 사장님이 **기존 코드 전체**(280개 tsx, `src/app` + `src/components`)에 대한
  일괄 정리를 명시 승인. 도메인별 배치로 진행 — 진행 상황은
  `project_classname_cleanup_20260715.md` 참조.
- **2026-07-16**: 규칙 정정. **초기 11개 배치는 잘못 적용됐다** — 마커와 Tailwind 유틸리티를
  한 className 에 병기하는 방식이었다. 올바른 방식은 className 에 **마커 이름만** 남기고
  유틸리티 조합 전체를 globals.css 의 `@apply` 규칙으로 빼는 것. 초기 11개 배치는
  **전면 재작업 대상**이다.

## 배치 작업 시 주의

- 새 마커 이름은 globals.css 에 이미 있는 이름과 **절대 충돌 금지**. 추가 전 매번 grep 으로 확인하고,
  기존 클래스 정의는 바꾸지 말고 새 이름만 추가한다.
- **기능·시각적 변경 절대 금지.** 순수 가독성 리팩터이므로 로직·조건문·props·렌더 결과가
  하나도 달라지면 안 된다.
- 동적/조건부 클래스와 진짜 동적 인라인 `style` 은 예외 — 그 부분만 className 에 남긴다.
