## 자문자답
- 기준: 마이페이지 = 나에 관한 것(내 기록·내 문서·내가 처리할 것·내 설정). 회사 전체 조회는 없다.
- 왜: 직원 계정은 인사관리·결재 관리가 안 보인다 → 자기 것을 볼 유일한 자리. 매일 묻는 건 "오늘 나 뭐 해야 하지".
- 반대: 대표·인사팀도 같은 구조(처리할 것에 결재가 많을 뿐). 파트너는 근태·연차·급여 갈래 숨김.
- 자동으로 못 푸는 것: 인사 정보 오류 → 정정 요청. 급여 금액 기본 가림.
