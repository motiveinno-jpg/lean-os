## 2. 자문자답

**① 무엇을 기준으로 판단하는가** — 사장님이 이 메뉴에서 묻는 질문은 "이번 달 벌었나(영업이익) / 어디서 벌었나(거래처·항목) / 어디로 나갔나(계정·거래처) / 지난달·작년보다 어떤가 / 이상한 데 없나". 이건 **회계 손익(발생주의·전표)** 의 질문이다. 통장에 돈이 들어왔나(현금)는 자금 전망이 답한다.
→ **손익 현황 = 확정 전표 기준(손익계산서와 같은 숫자)** 로 통일. 세금계산서·카드·통장 원본은 드릴다운(원천)에서 보인다.

**② 사용자는 왜 하는가** — 월초에 지난달을 돌아보고(무엇이 늘고 줄었나), 월중엔 이번 달 흐름을 확인하고(급증 비용·미수금), 결산 때 손익계산서로 넘어간다. 그래서 첫 화면은 **한 문장 결론 + 손익 구조(폭포수) + 무엇이 달라졌나(증감 표)** 여야 한다.

**③ 반대 경우** —
- 전표 처리가 밀려 있으면 손익이 비어 보인다 → 화면 위에 "전표로 만들지 않은 자료 N건" 안내(손익계산서와 동일 배너)와 수집·전표 링크. 숨기지 않고 **적는다**.
- 미분류 출금(계정 없음)이 있으면 판관비가 과소 → '미분류' 줄을 비용 표에 **별도로 보인다**(계정 이름 없이 합계만).
- 전기 값이 0이면 증감 % 는 계산 못 한다 → '—' 로 두고 금액 차이만.

**④ 자동으로 못 푸는 것** — 계정 분류·전표 처리는 사람이 한다. 화면은 "몇 건이 빠져 있는지"만 말하고 그 화면(수집·전표)으로 보낸다. 손익 현황이 대신 분류하지 않는다.

## 3. 결정

### 결정 1 — 기준: 손익 현황은 확정 전표(`fetchJournalLines`)만 본다
- **규칙**: 매출·비용·이익 전부 손익계산서와 같은 함수(`journal-reports`)로 셈한다. 세금계산서·카드·통장은 **드릴다운의 원천 줄**로만 나온다.
- **AS_IS ▶ TO_BE**: 매출=세금계산서 / 비용=예산 추정 / 월별=통장 ▶ 셋 다 전표. 화면 위에 "손익계산서와 같은 숫자입니다 · 전표 안 된 자료 N건" 한 줄.
- **적용 시점**: Phase 1(아래).
- **기존 데이터**: 예산 추정(`cash-budget`)은 **자금 전망**에 남는다(현금 관점). 손익 현황에서만 뺀다.
- **예외 순서**: 없음. 기준값은 회사설정이 아니라 고정(회계 원칙).

### 결정 2 — 갈래: 요약 · 매출 · 비용 · 월별 표 (탭 4개, 상자 안 파란 밑줄)
| 탭 | 조회 줄(머리 고정) | 결과 요약(머리 고정) | 본문(스크롤) |
|---|---|---|---|
| **요약**(새 기본) | 기간(월/분기/연, 월 단위) · 비교 칩(전월/전년동월) ‖ 엑셀 · 인쇄 | 매출 · 매출원가 · 판관비 · **영업이익** · 영업이익률 (비교 시 ▲▼%) | ① 한 문장 상태 판 ② 손익 구조 폭포수(매출→원가→판관비→영업이익) ③ **무엇이 달라졌나 표**(항목별 이번 기간 / 비교 기간 / 증감액 / 증감%) ④ **살펴볼 것**: 전월 대비 급증 비용 상위 5 · 30일+ 미수금 · 미분류 출금 · 전표 안 된 자료 |
| **매출** | 기간 · 검색조건(거래처 다중 · 매출 계정 다중 · 금액) · 빠른검색 | 매출 합계 · 거래처 수 · 건수 · 평균 단가 · 미수금 | ① 월별 매출 vs 전년(막대 + 표) ② **거래처별 매출 표**(거래처 · 건수 · 금액 · 비중 · 전년동기 · 미수금, 정렬·≡) ③ **항목(계정)별 매출 표** ④ 미수금 표(거래처 · 금액 · 경과일, 30일+ 강조) |
| **비용** | 기간 · 검색조건(비용 계정 다중 · 거래처 · 고정/변동 · 금액) · 빠른검색 | 비용 합계 · 인건비 · 고정비 · 변동비 · 미분류 | ① 월별 비용 vs 전년(막대 + 표) ② **계정별 비용 표**(계정 · 금액 · 비중 · 전월 · 증감 — 급증 ▲ 표시) ③ **거래처별 지출 상위 표** ④ 고정비(정기결제·인건비) 목록 ⑤ 미분류 출금 줄(합계 + 수집·전표 링크) |
| **월별 표** | 연도 · 셀 모드 칩(금액/전월비/전년동월/누계/구성비) | — | FlowMatrix 를 **전표 기준 행**(매출·매출원가·판관비·영업이익·영업이익률·비용 상위 계정)으로, 공용 머리단, 셀 클릭 드릴다운 유지 |
- **모든 표 = 공용 표**(정렬·≡·너비·쪽) · **줄 클릭 = 원천 팝업**(그 계정/거래처의 전표 줄: 날짜·적요·거래처·차변·대변 → 전표 열기).
- **AS_IS ▶ TO_BE**: 매출/비용 각각 한 문장 + 카드 2장 ▶ 요약 탭이 결론을, 매출/비용 탭이 표로 자세히.
- **적용**: Phase 1 요약+매출+비용 표(전표 기준), Phase 2 드릴다운·살펴볼 것, Phase 3 월별 표 교체.

### 결정 3 — 비교의 기준값: 비교 칩은 '전월'과 '전년동월' 둘 중 하나, 기본은 **전월**
- 규칙: 기간이 여러 달이면 '직전 같은 길이 기간'/'전년 같은 기간'. 전기 0 이면 % 대신 '—'.
- 누가 정하나: 사용자가 그때그때(조회값 자동 기억 금지 → 내 조건에 저장 가능).

### 결정 4 — 매출 계정·비용 계정의 묶음은 계정과목표(회사설정)를 따른다
- 규칙: `account-nature`(nature·section)로 매출/원가/판관비/영업외를 가른다. 회사가 계정을 추가하면 자동으로 표에 들어온다. 화면에 하드코딩 안 함.

### 결정 5 — '살펴볼 것'은 규칙 4개만, 처리는 사람이
- 급증 비용: 전월 대비 +50% 이상이고 금액이 판관비의 5% 이상인 계정 상위 5
- 미수금: 30일 초과 거래처(원장 기준)
- 미분류 출금: 계정 없는 통장 출금 합계
- 전표 안 된 자료: `countUnposted`
- 각 줄은 '보러 가기' 링크만(자동 처리 없음 — 자동화 기본구조: 제안은 자동, 확정은 사람).

## 4. 누락 점검
- 권한·RLS: 읽기 UI, `/reports:*` 권한 게이트 그대로. 해당없음. 역할: 멤버도 같은 표준.
- 빈 상태: 전표 0건 → "전표가 없습니다 — 수집·전표에서 전표를 만들면 여기 손익이 채워집니다"(collect-empty) + 전표 안 된 자료 건수.
- 경계값: 전기 0(% 없음), 음수 매출(환입) 표시 '( )', 단수 기간(한 달) 비교 라벨.
- 중복 실행: 해당없음. 마감: 회계 마감(회사설정 › 회계마감) 이전 기간은 잠금 표시 아이콘만.
- 기존 데이터: 예산 추정 화면은 자금 전망으로(링크 안내 1줄). localStorage 조회값 없음.
- 파급 화면: 경영 요약의 '이번 달 손익/매출/비용' 카드 → 같은 함수로 맞춘다(지금은 cash-budget). 대시보드 손익 위젯 확인 필요.
- 외부 전송: 없음. 인쇄·엑셀: ExcelMenu(표별). 모바일: 표 가로 스크롤(부품 규칙). 되돌리기: 해당없음.
