# 경영 요약 · 자금 전망 재편 기획

작성 2026-08-19 · 사장님: "경영요약과 자금전망 메뉴도 개편이 필요할 것 같아"
목업(동작): https://claude.ai/code/artifact/5a75bb46-83e2-4beb-b28d-81c1e2a23904

## 1. History
- 2026-07-08 두 화면 신설(질문 기반 4그룹): 경영 요약 = 문장 1줄 + 신호등 카드 + 손익 3칸 + 예정 3줄, 자금 전망 = 예정 지출(5종 나열) / 운영 가능·시나리오(직선 전망 D+7/30/60/90, ±10% 3칸) / 경영 흐름(flow).
- 2026-08-19 리포트 표준(상자·ReportHead)·손익 현황 재편으로 경영 요약 손익만 확정 전표로 바뀜. 나머지(현금·미수·예정)는 예전 세 갈래(통장·세금계산서 status·예산 추정) 그대로.
- lib 에 `getDailyCashProjection`(날짜별 예정 입출금 + 러닝 잔액, 스냅샷 저장 부수효과)이 있으나 UI 미사용. cash-pulse 전망은 `월 지출 × 일수` 직선.

## 2. 자문자답
- 기준: 경영 요약은 "지금 괜찮아?" → 신호 3개(돈 있나 / 벌고 있나 / 받을 돈·낼 돈) + 이유 + 다음 행동. 자금 전망은 "앞으로 돈 괜찮아?" → 날짜별 예정 항목을 뺀 잔액 곡선 + 최저점·부족 시점 + 확실도.
- 왜: 사장님은 숫자보다 "왜 그런지·뭘 해야 하는지"를 본다. 지금은 신호만 있고 이유·행동이 없다.
- 반대: 전표가 없어 손익이 실제보다 나쁘게 보이는 회사 → '벌고 있나' 판이 그 사실(미처리 N건)을 적는다. 예정 항목이 하나도 없는 회사 → 직선 추정만 점선으로 그리고 "등록하면 정확해집니다".
- 자동으로 못 푸는 것: 만기 없는 세금계산서(발행+30일 가정), 미등록 정기 지출, 부가세 예상, 급여 가정 → '틀릴 수 있는 곳' 판에 적고 고치러 가는 링크.

## 3. 결정(제안)
1. **경영 요약** = 세 신호 판(신호등·큰 숫자·세부 4줄·왜·링크) + **이번 주 챙길 것**(규칙: 30일+ 미수·미처리 전표·부가세 D-·급여 D-·고정비 등록값 vs 실제 차이·잔액 부족 예상, 사람이 체크하면 다음 주까지 숨김 — 로컬/사용자 값) + **달라진 것** 표(지난달 대비 금액 차이 상위). 조회 줄 = 기준 월 ‖ 엑셀·인쇄. 결과 요약 = 상태·잔액·영업이익·운영 가능·받을 돈·낼 돈(30일).
   AS_IS 문장+카드 나열 ▶ TO_BE 세 판+챙길 것+달라진 것. 적용: 1단계. 기존 데이터: 없음(읽기).
2. **기준 통일**: 손익=확정 전표(pnl-status), 현금=통장(bank_accounts·cash-pulse), 받을·낼 돈=거래처 원장 RPC `get_partner_ledger_by_year`(정산 반영). tax_invoices status 만 세는 미수 계산(11억 오류) 폐기.
3. **자금 전망** = 한 화면 3갈래 [전망 · 예정 항목 · 월별 흐름]. 전망 = 잔액 곡선(실선 확정·점선 추정·주황 시나리오) + 13주 자금 달력 + 틀릴 수 있는 곳 + 운영 가능 기간(지금 속도/확정 반영/시나리오/미수 전부 회수). 예정 항목 = 조회 표준 표(날짜·항목·구분·금액·그때 잔액·근거·확실도·상태, 검색조건 구분/확실도/거래처/금액, 빠른검색, 줄 클릭 → 원천). 월별 흐름 = 지금 경영 흐름(/reports/flow) 그대로 갈래로.
   AS_IS 예정 지출/운영 가능·시나리오/경영 흐름 ▶ TO_BE 전망/예정 항목/월별 흐름. 라우트 upcoming·outlook 은 전망으로 redirect.
4. **전망 계산** = 새 lib `cash-outlook.ts`: 오늘 잔액 + 날짜별 예정 항목(세금계산서 만기(없으면 발행+30일 · 추정), 급여(지난달 실지급 · 확정), 대출 원리금(확정), 정기 지출·고정비(확정), 부가세 예상(추정), 프로젝트 계약 회차(확정), 30일+ 미수(회수율 × · 추정)) → 러닝 잔액. 확정 항목이 없는 날은 지금 속도(월 지출÷30) 추정. `getDailyCashProjection` 로직 재사용하되 스냅샷 쓰기는 안 함(읽기 화면).
5. **시나리오** = 보기 설정 문법(고르고→적용, 걸린 칩, ★ 저장): 지출 ±%, 입금 지연 일수, 미수 회수율, 추가 자금 한 건, 큰 지출 한 건 → 곡선 하나 더. 실제 숫자 불변.
6. **대시보드 경영 요약 위젯** = 세 신호 축약(같은 함수).
