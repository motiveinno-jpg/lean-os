## 자문자답
- 기준: ①지금 그룹 안에서는 1번, 다른 그룹으로는 2번 안에 닿는가 ②메뉴가 50개가 되어도 스크롤이 안 생기는가.
- 왜: 회계 담당자는 하루 종일 파이낸스 안, 대표는 홈·분석·워크스페이스를 오간다 — 둘 다 "내 그룹만 펼쳐진" 상태를 원한다.
- 반대: 그룹을 자주 오가는 사람 → 레일 hover 미리 보기 + ⌘K. 그룹 안 12개 초과 → 패널 안 층 소제목(파이낸스 기초/자료/기장/예정).
- 자동으로 못 푸는 것: 지금 그룹은 주소가 정한다. 마지막에 본 그룹은 기억하지 않는다(조회값 자동 기억 금지와 같은 원칙).

1. 레일(60px) 그룹 아이콘 7개 + 두 글자 이름 / 패널(196px) 고른 그룹 항목만 + 그룹 이름·개수 + 층 소제목. AS_IS 한 줄 목록 ▶ TO_BE 레일+패널. 적용: sidebar.tsx, app-shell 폭. 기존 데이터: 로컬 collapsedGroups 폐기.
2. 지금 그룹 = 주소가 정한다. 화면이 바뀌면 그 화면의 그룹으로. 홈 그룹은 레일 맨 위 고정, 로고 = 대시보드.
3. 접기 = 레일만. 아이콘 hover → 패널이 떠서 보이고 벗어나면 닫힘.
4. 배지: 항목에 숫자, 레일 아이콘엔 빨간 점만.
5. 안 바꾸는 것: ⌘K, 헤더, 그룹 색 계열, 권한 숨김, 파이낸스 A안 순서.
