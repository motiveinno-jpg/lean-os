# 재고 자동화(토큰 없는 규칙형) + 버튼 간소화 기획 (2026-08-27)

> 사장님: "재고 쪽에 AI 자동화 기능을 넣고 싶은데(토큰 사용 말고) 자동화로 넣을 수 있는 것들을 기획. 버튼부터 간소화할 수 있는 것까지 고려."
> 원칙: **제안은 자동, 확정은 사람**(모든 자동화 공통). 규칙·통계·장부 대조만 쓴다 — LLM 호출 없음. 출처를 화면에 적는다(`규칙` / `장부 대조` / `내가 배운 규칙`).

## 1. History — 지금 왜 이 모양인가
- 2026-08-26~27 생산 로스·불량(결정 28~35), FIFO 원가·이익관리(36~42), 수율 임계값, 엑셀 일괄, 값 필터 검색조건 이동, 도구▾ 묶기까지 왔다. 기능은 다 있는데 **사람이 매번 눌러야** 움직인다.
- 이미 있는 자동 요소: 안전재고(`products.safety_stock`) → 현황 '부족' 표시, 수율·로스 경보(설정 임계값), 생산·매출원가·재고자산 초안(주기), 바코드 스캔 +1, 엑셀 양식.
- 없는 것: **다음 행동을 대신 준비해 두는 것** — 발주서 초안, 실사 차이 정리 초안, 품목 자동 채움, 창고 자동 배정.

## 2. 자문자답
1. **기준** — 자동화가 되려면 판단 기준이 숫자로 있어야 한다: 안전재고·리드타임·평균 일 소진량·BOM·거래처 최근 단가·창고 규칙. 기준이 없는 것(예: 어느 거래처에 발주할지 두 곳이 같을 때)은 **후보를 보여 주고 사람이 고른다.**
2. **왜** — 재고 담당이 매일 하는 일은 "부족한 것 발주·들어온 것 입고·나간 것 출고·차이 맞추기·전표". 이 네 가지의 '입력 준비'를 자동으로.
3. **반대 경우** — 시즌성(평균이 틀림)·신제품(이력 없음)·수동 조정 중인 품목. → 품목별 **자동화 끄기** 플래그, 이력 30일 미만은 제안 안 함.
4. **자동으로 못 푸는 것** — 발주 확정(돈), 실사 차이 승인(재고자산), 불량 원인. 화면에 "왜 못 푸는지" 적는다.
