## 참고 덱에서 가져온 것

### 아드리엘(내실)
- **기능 장표 = 제목 / |부제| → 고객의 말 2개(구어체·빨강) → 기능 3개 + 캡처**
  한 장만 봐도 "무엇을·어떻게·왜 필요한가·진짜 되는가"가 끝난다.
- **연동 커넥터 그리드를 앞쪽에** — 남의 이름(은행·카드사·국세청)으로 신뢰를 먼저 준다.
- **사용 예시 챕터** — 같은 제품을 용도를 바꿔 반복해서 보여 준다. 화면이 분량의 70%.
- 부제는 파이프(`| … |`)로 감싼다. 고객 인용은 "~해요" 구어체, 빨강은 **아픈 지점에만**.

### 마인드노크(외형)
- 글꼴 한 가족 + 굵기 3단계, **중간 크기(14~16pt)를 안 쓴다** — 제목 23 / 부제 12.5 / 본문 9.8.
- 캡처는 **흰 카드 + 얇은 테두리**에 담고 캡션. 전체 화면 그대로 넣는 장표는 사용 예시뿐.
- 주색 3톤 + 강조 1색, 강조는 한 장에 한 곳. 챕터에도 메시지 문장.
- 안 가져온 것: 짙은 보라 풀밴드·노랑 형광·조직도/예산표(입찰 제안서 전용).

## 만들며 고친 것 (기록)
1. **기능 3열 카드 → 3행 배치.** 제품 조각은 대개 5:1 로 가로가 길어, 3열 카드에 넣으면
   우표처럼 작아지거나 좌우가 잘려 무슨 화면인지 알 수 없었다. 행으로 눕혀 캡처 폭을 8.7"로 줬다.
2. **조각 크롭 시작 x 400 → 350.** 계좌명·거래처명이 왼쪽에서 잘리던 문제.
3. **이미지 왼쪽 정렬.** 가운데 정렬이면 조각 왼쪽 라벨이 가운데로 밀려 시선이 흩어진다.
4. **27번 사용 예시를 거래처 원장 → 손익 계산으로 교체.** 원장은 거래처 미선택 상태라
   "왼쪽에서 거래처를 고르세요" 빈 화면이 찍혔다. 빈 화면을 소개서에 넣지 않는다.
5. 16번 기능 장표에서 같은 조각(f-ledger)이 두 번 쓰이던 것 → 미수 위젯으로 교체.
