## ① 채권·채무 연령표 (배포 2026-08-27)

### History

- 2026-08-19 요약 줄에 **매출 미수 경과 칩**(0–30/31–60/61–90/90+) — 합계뿐, 매출처만, 거래처별 분해 없음.
- 대시보드 `receivables-preview` 에 독촉 문구 복사가 있으나 원장과 따로 놀고 기록이 남지 않았다.

### 자문자답
1. **기준** — 전표처리된 세금계산서의 미정산 잔액(total − settled_amount), 경과일 = 오늘 − 발행일. 원장 칩과 같은 기준이라 숫자가 서로 맞는다. 지급기일 칸이 없으므로 발행일 기준(이카운트도 기본은 발행일).
2. **왜** — "누구한테 얼마가 얼마나 오래 밀렸나"를 한 표로. 독촉 우선순위와 대손 판단의 출발점.
3. **반대 경우** — 계산서 없이 전표로만 잡힌 채권(이월·수기)은 계산서 기준 표에 못 나온다 → 원장 보기로 안내(결정 53). 취소 계산서(마이너스)는 잔액 ≤ 0 이라 자연히 빠진다.
4. **자동으로 못 푸는 것** — 독촉 발송. 문구만 만들어 복사하게 하고 발송·기록은 사람.

### 누락 점검
권한: `/partners/ledger` 그대로(money). 빈 상태: 미정산 계산서 없음 안내. 경계값: 잔액 ≤ 1원 제외, 발행일 없으면 0일. 중복실행: 기록은 append 뿐. 마감: 해당없음. 파급: 거래처 원장 화면만. 엑셀: 후속(연령표 시트). 모바일: 표 가로 스크롤(min 1080). 되돌리기: 기록은 거래처 메모에서 편집.
