# PDF·PNG 내보내기는 PowerPoint COM (PowerShell) 사용 — deck 문서 하단 참조

## 캡처 원칙 (사장님 지시)
- **설명 항목 1개 = 캡처 조각 1개.** 페이지 전체 뷰는 표지 히어로 1장에만 쓴다.
- 모두 **deviceScaleFactor 2**(폭 1600 → 3200px). PPT 안에서 확대해도 흐려지지 않는다.
- 조각 배치는 두 형식을 비율로 골라 쓴다:
  · **카드형(3~4열)** — 세로가 있는 조각(템플릿 격자·회의 카드·딜 카드). 비율 유지.
  · **행형(2단 반복)** — 가로로 긴 표·차트. 폭을 꽉 채우고 넘치는 쪽만 잘라 글자가 읽히게.
  (`deck-build.py` 의 `feature_sections` / `feature_rows`)
