# 근로소득 연말정산 (2026-10-14)

사장님: 위하고에 있고 우리에 없는 세무회계 기능 추천 → 3순위 연말정산 "추천순서대로 진행".
결정(10/14): 공제 자료 = **입력 폼 먼저, 간소화 PDF 자동 읽기는 다음** · 입력자 = **직원 본인 + 급여 담당자 확인**.

## ① History
- 인사 › 증명서 › '연말정산 자료'는 직원별 간소화 자료 **제출 상태**(year_end_tax_status pending/submitted/reviewed)와 안내 메일만.
- 계산이 없어 원천세 A04(연말정산)·연간 근로 지급명세서 '결정세액'이 비어 있다(세무 2차 5단계 한계로 적어 둠).

## ② 자문자답
1. 기준: 소득세법 근로소득 연말정산 — 총급여(발송된 급여 명세 과세분, 결정 101) → 근로소득공제 → 소득공제 → 과세표준 → 세율 → 세액공제 → 결정세액 − 기납부(매월 원천징수) = 환급/추징.
2. 왜: 매년 1~2월 모든 직원 회사가 한다. 결과가 2월분 원천세(A04)·3/10 지급명세서로 이어진다.
3. 반대 경우: 중도 입사(전 근무지 급여·기납부) · 중도 퇴사(퇴사 때 정산) · 표준세액공제가 더 유리한 사람 · 추징이 1천원 미만.
4. 자동으로 못 푸는 것: 부양가족 소득요건·중복공제, 주택자금 요건, 신용카드 소비증가분(전년 사용액), 기부금 이월, 외국인 단일세율, 중소기업 취업자 감면 → 입력 칸·'세무사 확인'.

## ③ 결정 (269 제안)
- 규칙 상수 = `lib/tax-forms/year-end.ts` 한 곳, **2025년 귀속 기준**(RULE_YEAR). 개정되면 상수만 고치고 화면에 기준 연도 표시.
- 표준세액공제 vs 특별공제: 둘 다 계산해 결정세액이 작은 쪽(연말정산 프로그램 관행).
- 저장: 직원이 공제 입력·제출 → 담당자가 급여 자료(총급여·4대보험·기납부)와 합쳐 계산·확정. 확정본은 고정 — 급여 자료·결과를 그때 값으로 남김. 재계산하려면 '확정 풀기'(→ 제출됨) 후 다시 확정. 반려는 사유를 남기고 직원이 고쳐 다시 제출.
- 베타: feature_rollout 'year_end_settlement' 모티브 먼저.

## ⑤ 단계
1. ✅ 계산 엔진 + 단위 검사 14건.
2. ✅ DB year_end_settlements(RLS 본인·마스터·급여 권한, 가드: 직원은 작성 중/제출만·확정 뒤 못 고침) + 마이페이지 › 급여·계약·증명 입력 팝업(입력하는 대로 예상 결과)·임시 저장·제출.
3. ✅ 인사 › 증명서 › 연말정산 자료 위 '연말정산 계산·확정' 표(근로자만, 프리랜서·일용 제외) — 줄 클릭 팝업에서 확정·반려(사유)·확정 풀기, 엑셀. E2E: QA 직원 제출 → QA 대표 확정 → 직원 화면에 결정세액·환급 표시, 시험 행·임시 게이트 삭제.
   - 버린 안: 담당자가 직원 대신 입력 — 사장님 결정(직원 본인 + 담당자 확인)으로 담당자 화면은 읽기 전용.
4. ✅ 원천세 A04·연간 근로 지급명세서 결정세액 연결.
   - 기준: 확정한 연말정산(status confirmed)만 — 추정치는 신고서에 넣지 않는다. 반영 달 = 귀속연도 다음 해 **2월 지급분**(규격: A04 인원·총지급액은 귀속·지급 2월/제출 3월에만).
   - A04 = 인원·연간 총급여(종전 포함)·차감징수세액(환급 음수, 규격상 A04·A06 음수 허용) → A10 = A01 + A03 + A04.
   - 가감계 음수(환급 > 간이세액)면 ⑮ 일반환급 = 그 크기, ⑲ 는 다른 소득 세액까지, A99 소득세 = 양수 가감계의 합(규격). 남은 환급은 ⑳ 차월이월.
   - 전자신고 파일: A04 + A06(분납 없음 → 같은 세액, 규격 'A04 = A05 + A06'), Header 연말정산여부 Y, 음수는 '-' 부호가 폭 안에. A10 음수는 규격상 허용 코드가 아니라 막고 홈택스 직접.
   - 연간 근로 지급명세서: 확정한 사람만 결정세액·차감징수세액, 나머지 '(미확정 · 세무사)'.
   - 원천세 2월분 '연말정산' 패널 → 인사 › 증명서 › 연말정산 자료 딥링크(?view=yearend).
   - 다루지 않음: 중도 퇴사자 정산(A02), 반기 신고자(3월 환급 신고), 분납(A05).
5. ✅ 간소화 PDF 불러오기 — 사장님 결정(10/14): **직원 브라우저 안에서만**(서버·AI 전송 없음, 원본 저장 없음) · 실물 샘플로 구조 확인.
   - 기준(실물 2025년 귀속 14쪽): 쪽마다 「YYYY년 귀속 … 증명서류 [항목]」 → '성 명' 다음 줄 = 사람 → '인별합계금액'(여러 쪽이면 마지막 쪽).
     카드 3종은 '일반·전통시장·대중교통·문화체육(·주택임차료)·합계금액' 집계 줄. 의료비는 의료비·안경(1인 50만)·산후조리(200만) 따로.
   - 소득기준 초과 부양가족(첫 장 명단 Y)은 의료비만 넣고 보험·카드·교육·기부는 기본으로 뺀다(기본공제대상자 요건). 건강·고용·국민연금은 급여에서 → 참고만.
   - 읽은 값은 제안: 항목·사람·금액·넣을 칸(셀렉트)·넣기 체크 → '공제 칸에 넣기'는 고른 칸만 PDF 합계로 바꾸고 나머지 칸은 그대로. 칸 미정(기부금·가족 교육비 등)은 고르거나 끌 때까지 넣기 막힘.
   - 비밀번호 걸린 PDF는 비밀번호 칸. 귀속연도가 정산 연도와 다르면 경고.
   - 실물에 없던 항목(기부금·월세·연금저축·주택자금·학교 교육비)은 같은 틀로 찾되 칸을 확신 못 하면 '확인 필요' — 실물 생기면 보강.
   - 버린 안: AI(Claude) 읽기(의료·카드 내역 외부 전송), PDF 첨부 XML 읽기(이 PDF엔 첨부 없음 확인 — 국세청 추출 모듈 영역).
6. ✅ 중도 퇴사자 정산(A02) — 인사 연말정산 표에 그 해 퇴사일(resignation_date)이 있는 근로자를 '중도 퇴사 YYYY-MM-DD'로 넣고,
   담당자가 직접 저장·확정(퇴사자는 마이페이지 접근이 어렵다). 확정 result 에 kind 'resign'·settleMonth(퇴사월) — DB 칸 추가 없음(result 는 담당자만 쓴다).
   원천세: 퇴사월 지급분 A02(음수 허용, A10 가감), 2월 A04 에선 제외. 전자신고 A02 레코드(연말정산여부 N 유지 — 규격상 A04·A05·A06·A26·A46 만 Y).
   공제는 보통 기본공제·표준세액공제까지 — 카드·의료비 등은 퇴사자 5월 종합소득세(화면 안내). 버린 안: kind/settle_month DB 칸(가드·타입 변경 대비 이득 없음).
7. 모티브 실사용 후 전체 오픈 · 반기 신고 · 분납(A05).
