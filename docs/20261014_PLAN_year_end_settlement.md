# 근로소득 연말정산 (2026-10-14)

사장님: 위하고에 있고 우리에 없는 세무회계 기능 추천 → 3순위 연말정산 "추천순서대로 진행".
결정(10/14): 공제 자료 = **입력 폼 먼저, 간소화 PDF 자동 읽기는 다음** · 입력자 = **직원 본인 + 급여 담당자 확인**.

## ① History
- 인사 › 증명서 › '연말정산 자료'는 직원별 간소화 자료 **제출 상태**(year_end_tax_status pending/submitted/reviewed)와 안내 메일만.
- 계산이 없어 원천세 A04(연말정산)·연간 근로 지급명세서 '결정세액'이 비어 있다(세무 2차 5단계 한계로 적어 둠).

## ② 자문자답
1. 기준: 소득세법 근로소득 연말정산 — 총급여(발송된 급여 명세 과세분, 결정 101) → 근로소득공제 → 소득공제 → 과세표준 → 세율 → 세액공제 → 결정세액 − 기납부(매월 원천징수) = 환급/추징.
2. 왜: 매년 1~2월 모든 직원 회사가 한다. 결과가 2월분 원천세(A04)·3/10 지급명세서로 이어진다.
3. 반대 경우: 중도 입사(전 근무지 급여·기납부) · 중도 퇴사(퇴사 때 정산) · 표준세액공제가 더 유리한 사람 · 추징이 1천원 미만.
4. 자동으로 못 푸는 것: 부양가족 소득요건·중복공제, 주택자금 요건, 신용카드 소비증가분(전년 사용액), 기부금 이월, 외국인 단일세율, 중소기업 취업자 감면 → 입력 칸·'세무사 확인'.

## ③ 결정 (269 제안)
- 규칙 상수 = `lib/tax-forms/year-end.ts` 한 곳, **2025년 귀속 기준**(RULE_YEAR). 개정되면 상수만 고치고 화면에 기준 연도 표시.
- 표준세액공제 vs 특별공제: 둘 다 계산해 결정세액이 작은 쪽(연말정산 프로그램 관행).
- 저장: 직원이 공제 입력·제출 → 담당자가 급여 자료(총급여·4대보험·기납부)와 합쳐 계산·확정. 확정본은 고정 — 급여 자료·결과를 그때 값으로 남김. 재계산하려면 '확정 풀기'(→ 제출됨) 후 다시 확정. 반려는 사유를 남기고 직원이 고쳐 다시 제출.
- 베타: feature_rollout 'year_end_settlement' 모티브 먼저.

## ⑤ 단계
1. ✅ 계산 엔진 + 단위 검사 14건.
2. ✅ DB year_end_settlements(RLS 본인·마스터·급여 권한, 가드: 직원은 작성 중/제출만·확정 뒤 못 고침) + 마이페이지 › 급여·계약·증명 입력 팝업(입력하는 대로 예상 결과)·임시 저장·제출.
3. ✅ 인사 › 증명서 › 연말정산 자료 위 '연말정산 계산·확정' 표(근로자만, 프리랜서·일용 제외) — 줄 클릭 팝업에서 확정·반려(사유)·확정 풀기, 엑셀. E2E: QA 직원 제출 → QA 대표 확정 → 직원 화면에 결정세액·환급 표시, 시험 행·임시 게이트 삭제.
   - 버린 안: 담당자가 직원 대신 입력 — 사장님 결정(직원 본인 + 담당자 확인)으로 담당자 화면은 읽기 전용.
4. 원천세 A04(정산 지급월)·연간 근로 지급명세서 결정세액 연결. 그다음 간소화 PDF 읽기.
