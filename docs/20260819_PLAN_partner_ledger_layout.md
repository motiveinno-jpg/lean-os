## 자문자답
- 기준: 화면의 단일 목적 = "거래처 하나의 원장을 읽고, 틀린 줄은 그 자리에서 전표를 고친다". 원장 칸이 상자 대부분이어야 한다.
- 왜: ①이 거래처에 얼마·언제·무엇 때문에 남았나 ②오래된 미수를 골라 독촉 ③틀린 줄 수정. ①③=원장 크게, ②=미수 경과로 목록 거르기.
- 반대: "누가 제일 밀렸나"만 보는 사람 → 목록이 잔액순이라 위 몇 줄이 답(막대 차트 불필요). 여러 거래처 훑는 사람 → 원장 머리 ‹ › 이전·다음.
- 자동으로 못 푸는 것: 경과는 계산서 발행 기준이라 원장 총액과 다를 수 있다 → 요약 줄에 "차이 정상" 유지.

## 결정(제안)
1. **카드 2장 → 결과 요약 줄(Stat)**: 총 미수금 · 거래처 수 · 미수 경과 4칩(금액·건수). 칩 클릭 = 목록에 경과 조건(걸린 조건 칩, 재클릭 해제). 막대 차트 삭제(잔액순 목록과 같은 정보). AS_IS 카드 250px ▶ TO_BE 요약 36px. 매입처 탭은 총 미지급금·거래처 수만. 기존 데이터 없음.
2. **좌 목록 300px(코드·거래처·잔액 + 엑셀용 체크) · 우 원장 나머지 전부, 상자 끝선까지.** 좌우 각자 스크롤, 원장은 머리단·합계 줄 고정에 몸통만 스크롤. 페이지 스크롤 없음. AS_IS 380 + 690×250 ▶ TO_BE 300 + ~1,050×520(14줄).
3. **↔ 넓게 토글**: 목록 접고 원장 전폭. 거래처는 머리의 피커(누르면 아래 목록·검색) + ‹ ›(목록 순서). 상태는 화면 안(기억 안 함).
4. **원장 표 칸**: 일자(고정폭, 안 꺾임) · 적요(왼쪽, 남는 폭, …) · 전표 #번호(팝업) · 차변(발생) · 대변(회수) · 잔액(오른쪽 tabular). 전기이월 회색, **합계 줄 바닥 고정**(차변 합·대변 합·기말 잔액). 매입처는 발생/지급.
5. 안 바꾸는 것: 탭, 조회 줄, 원장 머리 동작(+ 전표 입력·엑셀·상세·차액 마감), 줄 클릭 → 전표 수정 팝업, 체크 → 다중 엑셀, RPC.

## 버린 안
- 원장 팝업(모달): 거래처 바꿀 때마다 닫고 열어야 해 여러 거래처 훑기·고치기에 불리 → 넓게 토글 + ‹ › 로 대체.
- 상하 분할: 폭은 커지나 높이가 반 → 줄 수가 안 는다. 원장은 세로가 중요.
- 막대 차트를 '보기: 차트'로 남기기: 정보 중복, 옵션만 는다.
