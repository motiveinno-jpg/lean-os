# 기획 — 재고 › 이익관리: 원가 반영 이익, 선입선출(FIFO), 시점별 원가 변경 (2026-08-26)

> 사장님: "재고 쪽에 **이익관리** 메뉴. 구매·생산·판매를 통해 발생하는 이익을 원가가 반영된 상태로 보여 주고,
> 제품 원가가 변동됐을 때 **선입선출로 계산**되는 것, **특정 시점부터 원가가 변경**되는 것까지 총체적으로."
> 추론 형식: `docs/PLANNING_METHOD.md`. 결정 번호는 재고 결정 35 다음부터.

## 1. History — 지금 원가는 어떻게 계산되나

| 무엇 | 지금 | 문제 |

## 2. 자문자답

**① 무엇을 기준으로 이익을 판단하는가**
- 이익 = **판매 시점의 매출 − 그때 나간 물건의 취득 원가**. 원가는 "그 물건이 들어올 때 얼마였나"로 정해지고, 나갈 때 **어느 입고분이 나갔는가**를 정하는 규칙이 원가 방법(선입선출·이동평균)이다.
- 그래서 기준 단위는 **입고 층(layer)**: 입고 한 줄 = {품목, 일자, 수량, 남은 수량, 단가}. 출고 한 줄은 층을 앞에서부터 깎으며 원가를 확정한다. 이 기록(`출고 원가`)이 이익의 단일 원천이다.
- "구매·생산·판매를 통한 이익"은 세 가지 숫자로 갈린다:
  - **판매 이익(매출총이익)** = 매출(반품 차감) − 매출원가(FIFO). 이익의 본체.
  - **구매 기여** = 같은 품목의 매입 단가 추이·평균 매입가 vs 판매가 → 어디서 싸게 샀고 얼마에 파는가(마진 폭).
  - **생산 기여** = 제품 원가(자재 FIFO 원가 + 로스) vs 판매가 → 만들어서 남는가. 여기에 불량 폐기·로스비가 **차감**.
  - 총 이익 = 매출총이익 − 폐기·감모·재평가 손실(샘플·증정 출고 원가도 비용).

**② 왜 하는가**
- "이 제품 얼마 남나"를 시점·품목·거래처·채널별로 **믿을 수 있는 숫자**로. 단가가 오른 뒤에도 과거 이익이 안 바뀐다.
- 회계와 맞추려고 — 매출원가가 재고에서 나오면 손익계산서와 재고 현황이 같은 말을 한다.

**③ 반대 경우 (→ 예외)**
- 층이 부족한 출고(재고 음수·기초 원가 없음) → 원가를 지어내지 않는다. `원가 미확정` 수량으로 남기고 화면에 "원가 없는 출고 N개"를 적는다. 나중에 기초 원가를 넣거나 매입이 들어오면 **다시 계산**으로 채운다.
- 반품 입고(return_in) → 원래 판매의 원가로 되돌아온다(새 층, 단가 = 그 판매의 확정 원가). 매입 반품(return_out) → 남은 층에서 그 매입 단가로 깎는다.
- 창고 이동 → 원가 사건이 아니다(층은 품목 단위, 창고 무관).
- 실사 조정 + → 층 생성(단가 = 그 시점 이동평균), − → 감모 손실.
- 이동평균을 쓰던 회사가 FIFO 로 바꾼다 → **바꾼 날부터** 적용, 과거는 다시 계산하지 않는다(장부 흔들림 방지). 처음 켤 땐 전체 재계산 1회(과거 이익이 바뀌는 것을 화면에 미리 알린다).

**④ 자동으로 못 푸는 것 (→ 사람)**
- **기초 원가**: 층이 없는 재고(기초 등록·단가 없는 매입)의 단가는 사람이 넣는다(품목별 '기초 원가 입력').
- **원가 재평가(특정 시점부터 원가 변경)**: FIFO 에선 새 매입이 들어오면 원가가 저절로 바뀐다. 사장님이 말한 "특정 시점부터 변경"은 두 경우다 — (a) 남은 재고의 단가를 그 날부터 X로 본다(**재평가**, 차액은 평가손익) (b) 앞으로 들어오는 것부터 X(그냥 매입 단가). (a)는 사람이 날짜·단가·사유를 적어 만든다. 자동으로 판단하지 않는다.
- 생산 제품 원가에 **노무·경비**를 얹을지: 이번엔 자재 원가만(결정 31). 얹고 싶으면 '간접비 %'를 회사설정으로 — 사람이 정하는 값.

## 3. 결정

### 결정 36 — 원가는 '입고 층'과 '출고 원가' 두 표로 확정한다 (단일 원천)
- **규칙**: `stock_cost_layers`(입고 층: product, 원천 move_id, 일자, qty_in, qty_left, unit_cost, source ∈ purchase/opening/produce/return_in/count/reval/manual)
  · `stock_move_costs`(출고 원가: move_id, cost_amount, qty_costed, qty_uncosted, method, layers 사용 내역 json). 이익·현황·전표 전부 이 두 표만 읽는다. `v_stock_avg_cost` 는 층의 가중평균(현재고 평가)으로 다시 정의.
- **AS_IS ▶ TO_BE**: 전체 기간 평균 하나 ▶ 시점 있는 층 + 출고마다 확정 원가.
- **적용 시점**: Phase 1. **기존 데이터**: 첫 켜기 때 회사 전체를 일자순으로 1회 재계산(`rebuild_stock_costs(company, from)`). 단가 없는 옛 입고는 층 단가 null → 그 출고는 `원가 미확정`.

### 결정 37 — 원가 방법은 회사설정, 기본 **선입선출(FIFO)**. 이동평균도 고를 수 있다
- **규칙**: `company_settings.settings->costing = { method: 'fifo' | 'avg', since: 'YYYY-MM-DD', overhead_pct: 0 }`. FIFO: 오래된 층부터. 이동평균: 출고 시점까지의 층 가중평균 단가로 깎고 층은 비율로 줄인다. 바꾸면 `since` 부터만.
- **왜 FIFO 기본**: 사장님 지시 + 단가가 오르는 국면에서 재고 평가가 현실과 가깝고, "어느 입고분이 나갔나"를 사람이 눈으로 확인할 수 있다(층 표).
- **버린 안**: 후입선출(세법·K-IFRS 불인정), 개별법(로트 관리 없음).

### 결정 38 — 생산 제품의 원가 = 자재 실투입 FIFO 원가 ÷ (양품+불량) (+ 간접비 %)
- **규칙**: 완성 기록 저장·재계산 때 자재 투입(MTL) 줄의 확정 원가 합을 완제품 층 단가로 쓴다. 사람이 넣은 단가는 **참고값**(층 단가가 진실). 회사설정 `overhead_pct` 가 있으면 그만큼 얹는다(기본 0).
- 로스는 자재 원가에 이미 들어 있으니 제품 원가에 얹힌다(결정 31 그대로). 불량은 같은 단가로 불량 보류 창고 층 → 폐기 때 그 원가가 손실.
- **기존 데이터**: 옛 PRD 층은 사람이 넣은 단가 유지(자재 원가를 지어내지 않는다).

### 결정 39 — 특정 시점부터 원가 변경 = '원가 재평가' 문서
- **규칙**: 품목·일자·새 단가·사유를 적으면 그 날 기준 **남은 층 전부를 새 단가로** 갈아끼운다(층 source=`reval`, 옛 층은 qty_left 0 으로 닫고 이력에 남김). 차액 × 남은 수량 = **재고 평가손익**(이익관리 '손실'에 표시, 결정 41 전표에 재고자산평가손실/환입). 그 날 이후 출고부터 새 단가가 나간다. 그 날 이전 출고는 안 바뀐다.
- 화면 문구: "이 날부터 이 품목 남은 재고 N개의 원가를 ₩X로 봅니다(차액 ₩Y는 평가손익)". 되돌리기 = 재평가 문서 취소(층 복원).
- **왜 문서인가**: 설정값으로 바꾸면 누가 언제 왜 바꿨는지 사라진다. 재고는 전부 문서(결정 8 정신).
- **버린 안**: 품목 마스터 cost_price 를 바꾸면 그날부터 적용 — 이력이 없고 층과 어긋난다. cost_price 는 '참고 매입가·기초 원가 기본값'으로만 남긴다.

### 결정 40 — 재고 › 이익 메뉴 (2글자 '이익', 재고 그룹 '현황' 옆, 금액 권한)
- 갈래(상자 안 파란 밑줄, 위 그래프 → 아래 표):
  1. **종합** — 요약 줄: 매출 · 매출원가 · **매출총이익 · 이익률** · 손실(폐기·감모·재평가·샘플증정) · **순이익** · 원가 미확정 출고 N. 그래프: 일별 매출·원가·이익, 품목별 이익 상위/하위. 아래: 판매 문서별 이익 목록.
  2. **품목별** — 판매수량·매출·원가·이익·이익률·평균 매입가(기간)·현재 층 단가·현재고 원가. 품목 클릭 → 원가 이력.
  3. **거래처·채널별** — 누구에게 팔아서 남았나(채널 주문은 채널).
  4. **구매·생산** — 품목별 매입 단가 추이(층 단가 선그래프) vs 판매가, 생산 제품 원가 구성(자재·로스·간접비) vs 판매가, 폐기·로스 비용.
  5. **원가 이력** — 품목 선택 → 층 표(일자·원천·입고·남음·단가·상태) + 출고 원가 표(어느 층에서 얼마) + `원가 재평가` 버튼(결정 39) + `기초 원가 입력`.
- 조회 줄: 기간(기본 이번 달) · 품목/거래처/채널 검색조건 · 엑셀. 설정(원가 방법·간접비 %·다시 계산)은 회사설정 › 회계·세무 › 계정과목·분류 아래 '재고 원가' 절.
- 권한: `/inventory/profit` money, 직원 기본 비노출(defaultGrant 아님 — 이익은 재무 정보).

### 결정 41 — 매출원가·손실 전표도 주기 초안 (결정 33 확장)
- 생산 전표 초안과 같은 주기·같은 확정 흐름으로 **매출원가 초안**: 차변 제품매출원가/상품매출원가 · 대변 제품/상품(기간 확정 원가 합, 반품은 반대). 폐기·감모·샘플·증정은 각 손실 계정, 재평가는 재고자산평가손실/환입. 원가 미확정 출고가 있으면 초안 적요에 적고 만든다(0으로 잡지 않는다 — 그 줄은 빠졌다고 적는다).
- **적용 시점**: Phase 3. **기존 데이터**: 켜는 날부터.

### 결정 42 — 재계산은 '문서 저장 후 그 날부터' 자동 + 밤 1회 전체 + 버튼
- **규칙**: 문서 저장·취소·수정 시 `rebuild_stock_costs(company, doc_date)`(그 날 이후만 다시). 매일 02:00 KST 전체 정합 재계산. 원가 이력 화면에 `다시 계산` 버튼과 마지막 계산 시각. 계산은 SQL 함수(security definer) 한 곳 — 화면마다 다르게 세지 않는다.
- 재계산이 과거 이익을 바꾸는 경우(기초 원가 입력·재평가 취소)는 화면에 "N월 이익이 ₩X 바뀝니다"를 미리 보여 주고 사람이 누른다.

## 7. 사장님 결정이 필요한 것
1. 기본 원가 방법 **FIFO**, 이동평균 선택 가능 — 맞는지.
