## 자문자답
- 기준: 마스터가 이 화면만 보고 "이 사람이 무엇을 보게 되는지"를 30초 안에 알고, 잘못 누른 것을 저장 전에 알아채는가.
- 왜: ①새 직원 — 팀 템플릿으로 시작해 한두 개 손봄 ②역할 변경 — 몇 개 켜고 끔 ③"왜 이 메뉴를 못 보지" — 현재 상태 읽기.
- 반대: 금액 메뉴를 실수로 켜는 것이 가장 비싼 실수 → ₩ 표시 + 저장 확인에서 따로 줄. 화면 전체 선택은 없애고 그룹 스위치만.
- 자동으로 못 푸는 것: 세부 켜짐·접근 꺼짐 모순 → 세부 켜면 접근 자동, 접근 끄면 세부 함께 끔. '권한 부여' 칩은 마스터만(점선 잠금).

## 결정(제안)
1. **카탈로그 = 사이드바 순서·이름, 키 불변**: 홈(대시보드 재무 위젯·AI 브리핑 / AI 참모) → 파이낸스(통장 · 카드 · 거래처 · 수집·전표 · 세금·증빙[발행 대기·내역·현황] + 전자계산서·현금영수증 하위 줄 · 일반전표 · 매입매출전표 · 정기 지출) → 분석(분석·리포트[경영 요약·손익·자금 전망·회계 자료·부가세 — 한 키] · 거래처 원장) → 워크스페이스(프로젝트 · 결재 허브 · 전자계약 · 게시판 고정) → 인사관리(구성원 · 근태 · 근로계약·서식 · 파일보관함) → 회사 관리(회사 설정 · 요금제). 기본 제공은 표 바닥 한 줄. '자동 분류(/transactions)' 줄 삭제(부여된 키는 그대로 존중). AS_IS 파이낸스 둘·옛 이름 ▶ TO_BE 사이드바 1:1. 적용: PERMISSION_CATALOG 재배열·짧은 라벨(+desc 툴팁). 기존 데이터: perm_key 불변.
2. **표 한 장**: 그룹 구분 줄(오른쪽 '이 그룹 전부' 스위치) · 메뉴 줄 = 이름(₩=금액 보임) · 접근 스위치 · 세부 기능 칩. 접근 꺼지면 칩 흐림, 칩 켜면 접근 자동. 경로는 툴팁. 바뀐 줄 왼쪽 노란 선. AS_IS 카드 7장·체크 44 ▶ TO_BE 26줄.
3. **템플릿으로 시작 + 차이**: 표 위 템플릿 칩, 누르면 체크 교체(저장 전), 요약 줄에 "템플릿 'X' +2 · −1". 화면 전체 선택/해제 삭제.
4. **오른쪽 미리보기 '이 사람이 보게 될 메뉴'**: 그룹별 목록, 꺼진 메뉴 취소선, 금액 메뉴 있으면 "₩ 금액 정보 포함".
5. **저장 = 바뀐 것 확인 팝업(추가/해제 목록, 금액 ₩ 표시) → set_member_permissions**. 바뀐 것 없으면 저장 비활성, 되돌리기.

## 버린 안
- 역할 3종만(대표/회계/직원): 세부 위임을 이미 쓰고 있어 후퇴. 템플릿이 그 역할.
- 메뉴별 팝업에서 권한: 한 사람 전체 그림이 안 보임.
- 사이드바에 직접 체크: 남의 권한을 내 사이드바에서 만지면 헷갈림 → 미리보기로 모양만 빌림.
