## 3. 자문자답
1. **무엇을 기준으로 판단하나** — 방문자가 첫 두 화면 안에서 ①이게 뭔지 ②얼마나 넓은지 ③실제로 움직이는지를 알아야 한다. 구간 순서는 그 세 질문 순서다.
2. **왜 하나** — 지금 랜딩은 "깊이" 위주라 "이 회사가 뭘 다 하는지"가 늦게 보인다. 폭을 앞으로 당긴다.
3. **반대 경우** — 폭만 보여주면 "얕은 도구 모음"으로 읽힌다 → 바로 다음에 실제 화면 영상으로 깊이를 증명한다. 또 오두식 다색 아이콘·손그림 낙서·격식체를 그대로 가져오면 우리 앱 안 톤(선 아이콘·담백·해요체)과 어긋난다 → 장치만 가져오고 표현은 우리 것.
4. **자동으로 못 푸는 것** — 고객 후기(인터뷰 확보 전엔 자리만), 시연 영상(촬영 필요), 사용자 수(없음 → 실측 4개 수치로 대체).
