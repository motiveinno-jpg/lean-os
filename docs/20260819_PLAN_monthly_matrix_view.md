# 월별 표 재편 기획 — '보기 설정' 한 버튼, 셀에 답 두 개

작성 2026-08-19 · 사장님: "금액·전월대비·전년동월 이런 것도 검색조건으로 한 버튼에 모으는 게 깔끔할 것 같은데 여러 방면으로 생각해볼래?"
목업(동작): https://claude.ai/code/artifact/fd2f4858-8f87-49ed-9781-89e5b5186423 · 상위 기획: docs/20260819_PLAN_pnl_status_redesign.md

## 1. History
- 2026-07-08 월별 표 = 경영 흐름 FlowMatrix(통장 기준) 재사용, 셀 모드 토글(금액/전월비/전년동월/누계/구성비).
- 2026-08-19 손익 현황 재편 Phase 3 — 확정 전표 기준 새 표(매출·원가·판관비 계정 펼침·영업이익·이익률·영업외·순이익 × 12월+누계), 조회 줄에 금액/전월비/매출 대비 칩 3개.
- 문제: 보기를 바꾸는 손잡이가 조회 줄에 칩으로 늘어난다(전년동월·누계·구성비까지 넣으면 6개). 조회 표준 규칙 "값 필터·보기 옵션이 많으면 검색조건 한 버튼으로".

## 2. 자문자답
- 기준: 이 표는 '달마다 무엇이 얼마였고 어떻게 변했나'. 보기 옵션은 데이터를 바꾸지 않고 **그리는 법**만 바꾼다 → 검색조건 문법(고르고→적용, 걸린 설정 칩, 내 조건 저장)을 그대로 쓰되 이름은 **보기 설정**(값이 아니라 보기라서).
- 왜: 사장님은 "지난달보다 늘었나"를 금액과 함께 보고 싶다 → 모드를 오가게 하지 말고 셀 하나에 금액+비교값.
- 반대: 좁은 화면·달 비교 → 세로 방향. 분기 보고 → 분기 묶음. 계정이 많아 길어짐 → 행 구성(요약 4줄).
- 자동으로 못 푸는 것: 없음(표시 옵션뿐). 목표선은 회사설정 월 목표가 있을 때만.

## 3. 결정(제안)
1. 조회 줄 = [연도 ▾ · **보기 설정 ▾ (N)**] ‖ 내 조건 ★ · 엑셀 · 인쇄. 금액/전월비/매출 대비 칩 줄 제거. **AS_IS ▶ TO_BE**: 칩 3개 ▶ 버튼 1개 + 걸린 설정 칩.
2. 보기 설정 안: 표시값(금액/전월비 %/전년동월 %/매출 대비 %) · 함께 보기(없음/전월비/전년동월/전년 금액 — 셀 아래 작은 글씨) · 열 묶음(월 12/분기 4/반기 2) · 방향(가로: 항목↓ 월→ / 세로: 월↓ 항목→) · 행 구성(요약 4줄/판관비 계정 펼침/전 계정 펼침) · 강조(최고·최저 달 테두리 / 전월비 히트맵 — 비용은 늘면 빨강 / 0인 달 숨김 / 월 목표 매출선) · 누계 열 보이기.
3. 기본값(사용자 값, ★ 내 조건 저장 가능): 금액 + 함께 전월비 · 월 · 가로 · 판관비 펼침 · 최고최저+히트맵 · 누계 보임. 걸린 설정 칩 ✕ 로 하나씩 되돌림, '기본으로' 한 번에.
4. 변하지 않는 것: 확정 전표 기준 · 셀 클릭 = 원천 전표 · 엑셀 = 지금 보이는 모양 그대로.
5. 2차: 행 이름 클릭 → 그 행 12개월 미니 추이(막대+전년 곡선) 펼침 · 비교 연도 선택(재작년도).

## 4. 대안 검토(버린 것 포함)
- 비교값을 옆 열(12×2)로 → 너무 넓다, 버림. 칩 나열 유지 → 지금 문제, 버림. 모드 대신 툴팁으로만 비교값 → 손을 올려야 보인다, 버림(작은 글씨가 낫다). 분기/반기 → 채택. 세로 방향 → 채택(모바일·달 비교). 히트맵 → 채택하되 켜고 끔 + 범례. 목표선 → 회사설정 목표 있을 때만.

## 5. 누락 점검
권한·RLS 해당없음(보기만) · 빈 상태(전표 0 → 안내 그대로) · 경계값(전월 0 → '—', 매출 0 이하 → 이익률 '—') · 기존 데이터(내 조건 saved_queries 화면키 'pnl-monthly') · 파급(엑셀 헤더가 보기 설정 따라감, 분기 묶음 시 드릴다운은 세 달 합) · 인쇄(가로 방향 12열은 가로 인쇄 안내) · 모바일(세로 방향 권장) · 되돌리기 '기본으로'.
