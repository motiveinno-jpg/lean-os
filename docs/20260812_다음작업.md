## 2. ⏭ CODEF 카드 응답에서 **가맹점 사업자번호** 받아오기
- 증상: `card_transactions.raw_data->>'merchantBusinessNo'` 가 **2,771건 중 611건(22%)** 에만 있다.
  카드사별로 갈린다 — **BC카드 1,009건 0개 · 롯데카드 1,006건 0개**, 반면 'BC카드 9956' 은 37건 중 25개.
- 이 번호가 없으면 `merchant_tax_types`(구분: 법인·일반·간이·면세)를 못 채운다.
  구조·화면·국세청 조회는 **이미 다 만들어 뒀다**(5cf05c9d) — 번호만 들어오면 저절로 채워진다.
- ★ **원인을 이미 좁혀 뒀다** — `supabase/functions/codef-sync/index.ts` 약 676~700행 카드 분기가
  가맹점 **이름만** 뽑는다:
  ```
  const storeName = charge.resStoreName || charge.resMemberStoreName || charge.resUsedStore || "";
  ```
  **사업자번호를 뽑는 줄이 아예 없다.** 지금 raw_data 에 남는 611건은 CODEF 가 통째로 넣어 준
  원본 객체에 우연히 들어 있던 것이라, 카드사가 그 필드를 주면 남고 아니면 없다.
- 참고: 현금영수증 쪽은 이미 제대로 뽑고 있다 —
  `supabase/functions/cashbill-purchase-sync/index.ts:275` 의 `resMemberStoreCorpNo`.
  **카드 분기에도 같은 필드를 뽑아 `card_transactions` 에 칸을 만들어 저장하면 된다.**
  (지금은 raw_data 안에만 있어 조회가 느리고 없는 건이 많다)
- 작업 순서: ①CODEF 카드 응답 원본을 한 건 찍어 실제 필드명 확인(`resMemberStoreCorpNo` 가 오는지)
  ②`card_transactions.merchant_bizno` 칸 추가 ③sync 에서 채우기 ④기존 611건 raw_data 에서 백필
  ⑤그러면 `merchant_tax_types` 채우기가 저절로 동작한다.
- ⚠️ 홈택스 분기(hometax/cash-receipt)는 **BLOCKED** — 건드리지 말 것(CODEF 운영팀 답변 대기).
