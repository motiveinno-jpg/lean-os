- 자동으로 못 푸는 것: 누구에게 어떤 위젯이 중요한가 → 프리셋이 첫 답, 이후 사람이 켜고 끈 것이 이김. 배치는 로컬 저장(기존).

## 결정(제안)
1. **층 1 신호 6칸(공통)**: 통장 잔액 · 30일 뒤 잔액(부제 운영 가능 개월) · 이번 달 손익(확정 전표) · 받을 돈(원장, 90일+ 부제) · 낼 돈(30일) · 세금 D-day. lib/biz-summary 한 함수. 톤 선(좋음/주의/위험), 클릭 → 그 화면. AS_IS 신호+경영 요약 위젯+자산 중복 ▶ 신호 하나, 경영 요약 위젯 삭제.
2. **층 2 오늘 챙길 것(AI 제안 표기)**: 머리(이름 · AI 제안 · 생성 시각 · 다시 생성) + 한 문장 결론 + 표 5줄(우선순위 태그 · 제목 · 이동 →), 줄 클릭 = 이유 펼침, 근거 5줄은 '근거 보기'로 접음. AS_IS 700px ▶ ~220px. 로직·권한 그대로.
3. **자료 상태는 그 위젯 머리에** (사장님 2026-08-19 "위젯 안으로 — 통장은 통장, 카드는 카드"): 통장 거래 위젯 머리 "● 7시간 전 · 미분류 8,900 · [↻]", 카드 사용 위젯 머리 "● 2시간 전 · 미분류 340 · [↻]". ↻ = 그 채널만 동기화, 미분류 숫자 클릭 → 수집·전표 › 통장/카드. 점 색 = 6시간 안 초록 / 하루 넘김 주황 / 실패 빨강. 독립 줄·노란 배너·엑셀 업로드 버튼 삭제. 두 위젯을 다 끈 사람은 신호 '통장 잔액' 부제의 '7시간 전'이 남는다. 버린 안: 독립 '자료 상태 한 줄'(위젯과 따로 돌아 눈이 한 번 더 감).
4. **층 3 위젯 격자**: 3열 × 같은 높이(238px), 위젯 = 머리 한 줄(이름 · 개수/합계 · 전체보기 →) + 몸통(표 최대 5줄 또는 숫자 타일 2×2). 안에 상자 금지. 빈 위젯 한 줄 빈 상태. 드래그 순서 유지, **크기 조절 삭제**. 위젯 편집 → '보기 설정' 판(관점 프리셋 대표/회계/직원 + 켜기·끄기 + 기본으로).
   - 기본(대표) 9: 미수금 · 이번 달 매출·비용(3개월 막대) · 세금·납부 일정 ‖ 통장 거래 · 카드 사용 · 결재 대기 ‖ 최근 프로젝트 · 공지사항 · 오늘 일정·할 일.
   - 회계: 미수금 · 통장 거래 · 카드 · 세금 · 최근 세금계산서 · 결재 · 매출·비용 · 공지 · 오늘 / 직원: 오늘 일정·할 일 · 내 담당 업무 · 결재 대기 · 공지 · 구성원 · 최근 프로젝트.
   - 기존 로컬 배치는 새 키(v2)로 시작(옛 값 버림), 위젯 id 는 유지.
5. **개인 것은 마이페이지가 주인**: 출퇴근 카드 삭제(사이드바 버튼 + 마이페이지 근태), 큰 달력 → '오늘 일정·할 일' 표, 내 담당·내 할일은 직원 프리셋에서만 기본.
