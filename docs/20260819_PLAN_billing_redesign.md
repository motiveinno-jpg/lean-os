- 자동으로 못 푸는 것: 현재 요금제가 비교 표에 없는 옛 요금제(울트라) → '현재' 열을 더 그려 '사용 중'(버튼 없음).

## 결정(제안)
1. **갈래 3개 요금제 · 충전 · 결제** — 결제 수단 + 청구서 = 결제 한 탭(위 결제 수단 한 줄, 아래 청구서 표). 라우트 ?tab= 은 둘 다 결제 탭으로.
2. **요약 한 줄(모든 탭)**: "현재 요금제 X · 월 ₩ (VAT 별도) · 다음 결제 · 결제 수단 ●1234 / ⚠ 없음 · 구성원 N명". AS_IS KPI 카드 4 ▶ 한 줄.
3. **요금제 탭 = 사용량 표 + 비교 표**: 사용량(항목·이번 달·제공량·남음 막대, 무제한 표기). 비교 표 행=기능·열=요금제(무료·오너뷰 추천·옛 요금제면 '현재' 열), 열 머리 이름·가격·버튼(사용 중=회색, 추천 열만 파랑 '이 요금제로 변경'), 월간/연간 칩 표 위. 카드·VAT 안내는 각주 2줄, 해지는 맨 아래 작은 링크(확인 팝업). AS_IS 타일 6 + 카드 2 + 배너 + 빨간 상자 ▶ 표 2 + 각주 + 링크. 적용: billing/page.tsx·_components 렌더만, getPlans features 를 행으로 매핑(기능 키 없으면 텍스트 줄 그대로).
4. **충전 탭**: 남은 양 한 줄 + 충전 표(항목·단위 가격·수량·금액·[결제] btn-secondary) + 충전 내역 표. 무료면 표 대신 한 줄.
5. **결제 탭**: 결제 수단 한 줄(카드 ●1234 · 등록일 · 변경/삭제 / 없으면 ⚠ + 등록 버튼 2) + 각주 2줄 + 청구서 표(날짜·내용·금액·상태·PDF).
