# 인사 — ERP 공백 + 규칙형 자동화(토큰 0) + 버튼 정리 기획 (2026-08-27)

> 사장님: "오너뷰 인사에서 ERP적 관점에서 더 추가해야 할 메뉴나 기능들이 있는지 체크하고, 추가로 AI 자동화 기능도 넣을 수 있는 게 있는지 기획. 버튼 등 정리는 항상 명심할 것."
> 원칙(공통): **제안은 자동, 확정은 사람.** 규칙·집계·장부 대조만, LLM 호출 없음. 출처를 화면에 적는다(`규칙` / `근태 집계` / `요율표` / `장부 대조`).
> 인사 고유 제약: **직원 기본 비노출(연봉 예민)** — 새 칸·새 표는 전부 `/employees:salary` 뒤에. 전표엔 개인별 금액 금지(결정 55).

## 1. History — 지금 왜 이 모양인가
- 2026-05 급여대장(payroll_items·payslip_overrides)·명세 PDF(비밀번호 = 생년월일) → 2026-07 연차 원장(leave_grants, 법정 연차 cron) → 2026-08-24 근태 기준·가산수당 이관 → 2026-08-27 급여 전표 초안(결정 55). **입력·발급은 다 있는데, 사람이 매달 같은 일을 손으로 친다.**
- 이미 자동인 것: 법정 연차 발생(cron 2종), 자동 퇴근 마감(5분 cron), 결재 승인 → 휴가·연장 반영(`apply_approval_side_effects`), 결재 승인 → 계약서 생성, 급여 전표 초안, 명세 전월→당월 복사 제안, 감사 로그.
- **칸만 있고 계산이 없는 것**: 퇴직충당금(`employees.retirement_accrual` 숫자 하나), 발령(`employment_history` 자유 글자), 4대보험 회사부담(추정치 표시만), 연말정산(홈택스 링크 + 안내 메일).
- **일부러 멈춘 것**: 4대보험 취득·상실 EDI(`lib/insurance-edi.ts` — 건강보험 Web EDI 가 자체 txt 를 거부, XLSX 규격 전까지 신규 배선 금지 P0), 수당 자동 재계산(504 인시던트 3차 → 수동 버튼만, "pg_cron 1시간 + advisory lock" 별건으로 남음).
- 코드 형편: `EmployeesPageClient.tsx` 4,505줄에 급여·휴가·증명서·상세 패널이 다 들어 있다. `SalaryTab`(급여이력 557줄)은 라우팅이 끊긴 죽은 코드.

## 2. 자문자답
1. **기준** — 인사 자동화의 판단 기준은 이미 숫자로 있다: 근태 집계(연장·야간·휴일·지각·결근 분), 수당 단가(회사 기준), 4대보험 요율(연도별 법정), 평균임금(최근 3개월 급여 ÷ 일수), 근속(입사일), 계약 만료일, 잔여 연차. **없는 기준**: 평가·승진(사람의 판단) → 자동화 대상 아님.
2. **왜** — 인사 담당이 매달 하는 일: ① 근태 집계 → 수당 → 급여대장 → 명세 발송 ② 4대보험 고지서와 맞추기 ③ 입·퇴사 신고와 서류 ④ 연차·계약 기한 챙기기. 이 넷의 **입력 준비**를 자동으로.
3. **반대 경우** — 급여가 매달 다른 회사(시급·성과급)는 근태 집계가 곧 급여라 초안이 더 유용하고, 고정급 회사는 전월 복사가 곧 초안(이미 있음). 수습·단시간 근로자는 4대보험 적용 예외 → 직원별 **적용 여부 칸**. 이력 3개월 미만 직원은 평균임금 대신 약정 급여.
4. **자동으로 못 푸는 것** — 급여 확정·발송(돈), 퇴직금 지급, 4대보험 신고 제출(공단 규격·주민번호), 연말정산 계산(홈택스 BLOCKED). 화면에 "여기부터는 사람"이라고 적는다.
