## 자문자답
- 기준: 표를 안 열고도 ①지금 상태 ②챙길 것을 아는가. 카드 나열은 ②가 없다 → 마지막 구획은 항상 챙길 것 표(줄 클릭 → 그 행 팝업).
- 왜: 대표·PM 의 주간 점검 — 템플릿마다 같은 골격이어야 훑을 수 있다. 형태 갈아끼우기는 탐색이지 점검이 아님 → '자세히'로.
- 반대: 도넛·간트를 즐겨 쓰던 사람 → '자세히'에 지금 갤러리(어떻게 볼까·양식·지표 고르기) 그대로 보존. 기능 삭제 없음.
- 자동으로 못 푸는 것: 커스텀 템플릿의 유형 — 칸 타입으로 판별(금액 → 돈 > 날짜 2개 → 일정 > 흐름/담당 → 할 일 > 그 외 기록), 판별 근거를 머리에 표기.

## 결정(제안)
1. **공통 골격 4층**: 결론 한 문장(기준 명시) → 핵심 숫자 3~5(Stat, 경고 톤 칩) → 대표 그림 하나 → 챙길 것 표(지남 → 이번 주 → 고액 순, 8줄 넘으면 "외 N건 → 표 보기", 줄 클릭 = 그 행 편집 팝업). 도구는 [표로][자세히 ▾] 둘.
2. **유형별 대표 화면**:
   - 돈(예산·지출, 매출 흐름): 예산·집행·남음·집행률·결제 지남 / 그림 = 구분별 집행 가로막대(예산 대비) / 챙길 것 = 결제 지남·이번 주 결제·고액 미완료.
   - 할 일(할 일·진행, 요청·검수): 전체·완료·진행·기한 지남·이번 주 / 그림 = 단계 흐름 막대(칸반 열별) + 담당 부하 한 줄 / 챙길 것 = 기한 지남·이번 주 마감.
   - 일정(일정·마일스톤, 계약·갱신): 전체·완료·지연·다음 마감 D-day / 그림 = 미니 타임라인(오늘 선) / 챙길 것 = 지난 미완료 → 다가오는 순.
   - 기록(회의·결정): 그림 없음. 결정·논의 중·보류·후속 지남 / 본문 = 최근 결정 5줄 + 밀린 후속.
3. **내 지표 (2026-08-20 사장님 추가)**: 고정 한 장 아래 '내 지표' 구획 — ＋ 지표 추가(무엇을 볼까: 그 템플릿 칸에서 만들 수 있는 지표 × 어떻게 볼까: 막대·도넛·선·표) → 카드로 붙음. 카드마다 형태 전환·빼기·⠿ 순서. 저장 = 기존 정리 양식(presets) 그릇에 {metric, shape}[] — 사람·템플릿별 명시적 저장. 고정 4층은 커스터마이징 대상 아님(회사 공통의 읽는 눈 유지). 이 편집이 '자세히' 갤러리의 역할을 흡수 — 전역 '어떻게 볼까' 스위치·지표 고르기 제거, shapeFigures/templateFigures 는 카드 단위 재사용. 전체 요약(프로젝트 한 장)은 그대로.
