## 3. 자문자답
1. **무엇을 기준으로 판단하나** — 방문자가 어느 공개 주소로 들어와도 ①같은 제품으로 보이고 ②**앱에 실제로 있는 메뉴·이름·요금**만 말하고 ③무료 시작·상담까지 한 번에 가는가.
   원본은 셋: **메뉴 = 사이드바 NAV_GROUPS**, **요금 = DB subscription_plans**, **문구 어체 = v8(오두 어체)**.
2. **사용자는 왜 이 페이지에 오나** — 대부분 검색이다(계산기·블로그·/features 그룹 — sitemap 31개 중 17개가 옛 모양 — /features 그룹 5개 포함). **첫 화면이 `/` 가 아닌 사람이 더 많을 수 있다.** 그래서 머리·바닥·CTA 가 가장 먼저 통일돼야 한다.
3. **반대 경우** —
   - 세무사 페이지는 **읽는 사람이 다르다**(대표가 아니라 세무사). 본문 구성·어휘는 두고 껍데기(머리·바닥·토큰)만 바꾼다.
   - 계산기는 **검색 순위가 걸려 있다.** 주소·H1·FAQ 구조화 데이터·계산 로직은 한 글자도 안 바꾸고 모양만 바꾼다.
   - v8 에 문제가 생겨 v7 로 되돌려야 하면? → v8 은 09-09 부터 운영 중. **2주 무사고(09-23) 뒤**에 v7 을 지운다.
4. **자동으로 못 푸는 것** —
   - 새 메뉴 캡처(이익관리·자동 분류·고정자산·세무 신고·지원사업추천 등) — QA 시드에서 사람이 찍어야 한다. 낮에 찍으면 사장님 화면이 튕길 수 있다(교훈 09-07).
   - 어체 판단 — 페이지 전체 문자열을 바꾸므로 사장님 검토 1회.
   - `/ai` 와 v8 「AI 자동입력」 구간이 겹친다 — 페이지를 둘지 사장님 결정(아래 Q2).
