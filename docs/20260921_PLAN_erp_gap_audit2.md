## ① 기준 — 무엇을 "추가해야 한다"고 판단하나
- 5~20명 회사가 이카운트·더존·경리나라를 쓰면서 **세무사·거래처·은행에 실제로 내는 산출물**이 오너뷰에서 안 나오면 공백.
- 이미 쌓인 데이터로 만들 수 있는 것(입력 자리가 새로 필요 없는 것)을 앞에 둔다 — 09-17 교훈: 입력 없이 대장을 만들면 빈 표.
- 수요 근거(운영 회사 8곳 · 30일 활성 3곳)가 0인 것은 버린다.

## ③ 추천 순서
1. **계정별 원장 · 합계잔액시산표** — 세무사가 제일 먼저 달라는 자료. 데이터 이미 있음(journal_lines). 거래처 원장 시트(`lib/ledger-sheet.ts`)의 틀을 계정과목 기준으로 재사용. 분석 › 회계 자료 허브에 두 줄 추가 + 엑셀.
2. **2단계 인증** — 돈·급여를 다루는데 비밀번호 하나. Supabase Auth TOTP 기본 제공이라 서버 공사 없음. 마스터 선택 → 회사 강제 옵션 순.
3. **거래명세서 · 발주서 출력** — 재고 판매·구매 주문서에서 '인쇄' 하나. `lib/document-generator.ts` 재사용. 회사 직인·계좌는 회사설정에서.
4. **현금흐름표(직접법)** — 통장 거래의 분류를 영업·투자·재무로 묶어 월별 표. 손익·재무상태표 옆 세 번째 표. 간접법은 소규모 회사가 쓰지 않으니 버림.
5. **4대보험 취득·상실 XLSX** — 공단 공식 예제 XLS 를 사장님이 주셔야 규격을 맞출 수 있음(코드만으로 못 함).
6. 수요 생기면: 매입 3자 대조(재고 회사 전용) · 여신 한도 · 부서별 지출.
