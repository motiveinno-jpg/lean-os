# 오너뷰 (OwnerView)

**중소기업 대표를 위한 경영 OS.** 통장·카드·세금계산서·전표·재고·프로젝트·근태·급여·결재·메신저·전자계약까지, 흩어져 있던 회사 운영을 한 화면에 모아 자동으로 이어 줍니다.

- 서비스: https://www.owner-view.com
- 카드 등록 없이 무료로 시작할 수 있습니다. 기능은 전부 열려 있고, 발행·서명 같은 횟수만 제한됩니다.

---

## 왜 만들었나

소규모 회사는 은행 앱, 홈택스, 엑셀, 메신저, 캘린더를 따로 쓰면서 같은 숫자를 여러 번 옮겨 적습니다. 대표는 매달 "지금 돈이 얼마 남았지", "누가 안 줬지", "이번 달 얼마 남았지"를 알기 위해 여러 곳을 뒤집니다.

오너뷰는 그 원천 자료를 **자동으로 가져와 서로 이어 줍니다.** 사람이 옮겨 적는 일이 없어지면 숫자가 틀리지 않고, 대표는 매일 아침 한 화면에서 회사 상태를 봅니다.

## 무엇이 이어지나

| 시작 | 자동으로 이어지는 것 |
|---|---|
| 통장·카드 거래가 매일 수집된다 | 자동 분류 → 전표 → 손익·부가세 신고·월결산 |
| 세금계산서·현금영수증을 국세청에서 받아온다 | 전표 · 미수·미지급 관리 · 정산 |
| 상품 하나가 팔린다 | 재고 · 원가 · 이익이 함께 움직인다 |
| 직원이 출퇴근을 찍는다 | 근태 현황 · 연차 · 가산수당 · 급여명세서 |
| 견적서를 만든다 | 계약서 · 전자서명 · 세금계산서 · 매출 스케줄 |
| 아침이 된다 | AI 브리핑이 오늘 챙길 것을 정리한다 |

## 기능 지도

### 홈
- **대시보드** — 미수·매출·통장·카드·프로젝트·근태 신호와 오늘 챙길 것. 위젯을 끌어 원하는 대로 배치합니다.
- **알림** — 결재·휴가·서명·수집 결과 등 회사 안에서 생기는 모든 알림.
- **마이페이지** — 내 근태·휴가·급여·계약·결재 요청.
- **AI 참모** — 회사 자료를 근거로 답하는 대화형 참모. "이번 달 미수금 회수 우선순위는?" 같은 질문에 숫자로 답합니다.
- **지원사업 추천** — 업종·인원·매출로 걸러 주는 정부 지원사업과 서류 준비 현황.

### 재무
- **통장** — 은행 연동 자동 수집, 자동이체 판정, 잔액과 수입·지출 추이, 자동 분류 규칙.
- **카드** — 카드사 승인·청구내역 자동 수집, 가맹점 정보 보강, 전표 처리.
- **거래처** — 거래처 원장, 사업자번호 검증, 중복 방지, 미수·미지급 연령 분석.
- **수집·전표** — 통장·카드·계산서 자료를 받아 전표로 만드는 작업대. 중복 의심을 잡고 분류 규칙을 학습합니다.
- **세금·증빙** — 전자세금계산서 발행(한 장 쓰기, 여러 장 한꺼번에, 엑셀 일괄), 수정발행, 발행 현황. 홈택스 발행 서식과 같은 칸 순서로 씁니다.
- **전자계산서 · 현금영수증** — 면세 계산서와 현금영수증 발행·수집.
- **일반전표 · 매입매출전표** — 회계 전표 입력, 표준 계정과목 체계, 마감한 달 잠금.
- **고정자산** — 취득·상각(정액·정률)·장부가.
- **세무 신고** — 부가세 예정·확정 집계와 신고 자료.
- **정기 지출 · 현황** — 반복 지출 관리, 작성된 전표의 현황과 지표.

### 재고
- **품목** — 바코드·규격·자재구성(BOM)·노무경비. 엑셀에서 붙여넣어 한 번에 등록.
- **창고 · 주문 · 판매 · 구매 · 생산** — 주문서를 불러와 판매·구매 전표로, 생산은 자재 실투입과 로스까지 기록.
- **이커머스** — 스마트스토어·쿠팡 주문 가져오기, 송장 붙이기.
- **현황 · 이익관리** — 재고 현황, 불량·보류, 품목별 이익.

### 업무
- **일정 / 할 일** — 공용 캘린더. 회의·마감·납품·휴가 일정과 미리 알림.
- **프로젝트** — 표·칸반·캘린더·간트로 보는 프로젝트, 프로젝트별 메신저 채널, 견적에서 계산서까지 이어지는 흐름.
- **결재 허브** — 양식 기반 결재, 부서·직급 기준 결재선, 일괄 승인, 참조.
- **게시판** — 공지·매뉴얼·교육자료, 투표, 고정글.
- **파일보관함** — 폴더 권한과 자동 버전 관리, 계정·구독 정보 보관.
- **메신저** — 1:1·그룹·프로젝트별 대화, @멘션·파일·읽음 표시, 외부 파트너 초대.
- **전자계약** — 양식에 값을 채워 일괄 발송, 링크로 서명, 서명본 보관.

### 인사
- **구성원** — 디렉토리, 직책급 순 정렬, 권한 부여.
- **근태 관리** — 출퇴근, 지각 판정, 연장·야간·휴일 가산, 연차 자동 계산.
- **근로계약·서식** — 계약서 자동 채움, 4대보험 요율 반영, 급여명세서 발송.

### 분석 · 설정 · 도움말
- **분석·리포트** — 손익, 경영흐름, 자금 전망, 부가세, 거래처 원장.
- **회사 설정** — 기초정보, 회계·세무, 연동, 권한.
- **요금제·결제**, **공지사항**, **사용 가이드**, **고객센터**.

## 어떻게 쓰나

- 한 회사 안에서 역할은 **마스터**와 **멤버** 둘뿐입니다. 멤버는 마스터가 준 권한(메뉴·탭 단위)만큼만 봅니다.
- 목록이 있는 화면은 모두 같은 방식입니다. 검색조건 · 빠른검색 · 결과 요약 · 정렬 가능한 표 · 쪽 넘김.
- 격자형 입력(세금계산서 품목, 전표, 재고)은 마우스 없이 채울 수 있습니다. 엔터로 다음 칸, 화살표로 이동, 마지막 칸에서 엔터를 누르면 새 줄.
- 가입하면 바로 쓸 수 있고 도입비·세팅비는 없습니다. 인원이 많거나 도움이 필요하면 온보딩을 무료로 도와드립니다.
