## 구성 v3 — 장면(후킹) 중심 (2026-08-27 사장님 확정)

> 사장님: "핵심기능만 넣자니 ERP로 부족해보이고 다 넣자고하니 후킹이 없는 느낌"
> → **본문은 장면 6+1개, ERP 완결성은 지도 한 장**으로 층을 나눠 해결했다.

| # | 장 | 헤드라인 |
|---|---|---|
| 01 | 표지 | 입력하지 않는 ERP |
| 02 | 공감 | 사장님의 하루는 왜 안 끝나는가 (타임라인 5개 — 아래 장면들이 하나씩 해소) |
| 03 | 장면① 아침 | 출근하면, 오늘 챙길 일이 정리되어 있습니다 (08:30 해소) |

| 05 | 장면③ 세금 | 세금계산서, 홈택스에 안 들어가고 발행합니다 (11:00 해소) |
| 06 | 장면④ AI 참모 | 말로 시키면, 실행까지 합니다 |
| 07 | 장면⑤ 받을 돈 | 못 받은 돈을 시스템이 기억합니다 (14:00 해소) |
| 08 | 장면⑥ 앞날 | 석 달 뒤 잔액이 오늘 보입니다 |
| 09 | 장면⑦ 경영 숫자 | 돈 있나·벌고 있나, 세 신호로 정리됩니다 (경영 요약) |
| 10 | 장면⑧ 계약·결재 | 계약서는 링크 하나, 직인은 자동 (23:00 해소) |
| 11 | 장면⑨ 사람 | 급여·연차·증명서는 손 댈 일이 없습니다 |
| 12 | 장면⑩ 프로젝트 | 표는 이미 만들어져 있습니다 — 템플릿 8종 |
| 13 | 장면⑪ 재고 | 전산 재고와 실물 재고가 맞아떨어집니다 + 후킹 3(부족 먼저·작업지시 한 번·채널 중복 0) |

| 15 | AI 자동화 | 사람이 안 해도 되는 일 7가지 — 랜딩 AI_AUTOMATION 과 동일 목록, 장면 번호 back-ref |
| 16 | 전체 지도 | 그리고 전부 들어 있습니다 — 41메뉴 그리드 |
| 17 | 증거 | 저희가 먼저 15개월 썼습니다 (실측 4지표) |
| 18 | 도입 | 구축비 0 · 설치 0, 가입한 날 씁니다 |
| 19 | 문의 | 쓰시는 양식 한 장 보내주세요 — 그 양식으로 시연 |

**장면 장의 규율**: 발문(고객의 말) 1줄 + 헤드라인 1개 + 본문 3줄 이내 + 화면 1개 + 숫자 1개.
그 이상 쓰지 않는다. **후킹은 수사가 아니라 숫자와 장면으로 한다**(감성 문구 금지 — 2026-08-26).
**헤드라인은 회사에서 쓰는 말로** — '재고는 사실' 같은 추상 표현 금지, 전산 재고·실물 재고·출고·입고
같은 실무 용어로 쓴다 (2026-08-27 사장님).

## 규칙

- **가격을 넣지 않는다** — '도입 문의'로 마감 (사장님 확정 2026-08-25).
- **경쟁사 브랜드명 금지.** 동작하지 않는 기능 금지.
- **수치는 실측만** — `landing/content.ts` 의 `CASES` 와 같은 값. 랜딩과 다르면 신뢰를 잃는다.
- **화면은 본문(`<main>`)만** 촬영 — 사이드바·배경 포함 금지, `.messenger-fab` 숨김 (2026-08-26).
- 이미지는 `public/product/` 참조(공용 캡처) + `img/`(소개서 전용 타일·크롭).
