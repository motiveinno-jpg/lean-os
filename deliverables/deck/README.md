# 오너뷰 소개서 (고객 영업용 19장)

`index.html` 이 원본이다. **PDF 를 직접 고치지 말고 HTML 을 고친 뒤 다시 뽑는다.**

```bash
node deliverables/deck/render.mjs      # → deliverables/deck/오너뷰_소개서.pdf
```

## 규칙

- **가격을 넣지 않는다** — 19장은 '도입 문의' 로 마감 (사장님 확정 2026-08-25).
- **경쟁사 브랜드명 금지** — 03장 대조도 "기존 ERP" 로만 (비교광고 분쟁 방지).
- **동작하지 않는 기능 금지** — 계약 갱신 알림·계좌 이체 실행은 넣지 않았다.
- **수치는 실측만** — 18장 숫자는 `landing/content.ts` 의 `CASES` 와 같은 값을 쓴다.
  갱신 기준은 그 파일 주석 참조. 랜딩과 소개서가 다르면 신뢰를 잃는다.
- 이미지는 `public/product/` 를 그대로 참조한다(복사본을 만들지 않는다) — 랜딩 캡처를
  새로 찍으면 소개서도 같이 최신이 된다.
