# 블로그 캡처 라이브러리

`scripts/blog-capture.mjs _library '<JSON>'` 로 운영 화면(QA 시드 회사 = 샘플 자료, 개인정보 없음)을 찍어 둔 것.
클라우드 루틴이 브라우저를 못 띄울 때 여기서 골라 `public/blog/<slug>/` 로 복사해 쓴다. 화면이 바뀌면 이 PC에서 다시 찍어 갱신한다.

**폭 규칙(2026-09-04)**: 글은 네이버 블로그에 올라가고 본문 폭이 705px 다. 넓게 찍으면 그만큼 축소돼 표 글자가 안 보인다.
그래서 ①표가 넓은 화면은 `cut: { maxWidth: 1010, sidebar: true, pad: 24 }` 로 **열 경계에서 잘라** 찍고
(가로는 열 경계에서 딱 끊는다 — 다음 열 글자가 걸치면 '잘렸다'로 보인다),
②대시보드·게시판처럼 카드가 늘어선 화면은 `width: 1280~1460` 으로 **좁은 화면째** 찍는다. 어느 쪽이든 이미지 폭 2600px 를 넘기지 않는다.
